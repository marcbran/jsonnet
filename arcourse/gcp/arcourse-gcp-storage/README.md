## Installation

You can install the library into your project using the [jsonnet-bundler](https://github.com/jsonnet-bundler/jsonnet-bundler):

```shell
jb install https://github.com/marcbran/jsonnet/arcourse/gcp/arcourse-gcp-storage@arcourse/gcp/arcourse-gcp-storage
```

Then you can import it into your file in order to use it:

```jsonnet
local arcourse-gcp-storage = import 'arcourse/gcp/arcourse-gcp-storage/main.libsonnet';
```
