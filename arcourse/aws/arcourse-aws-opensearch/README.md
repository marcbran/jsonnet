# arcourse/aws/arcourse-aws-opensearch

> Arcourse nodes for Amazon OpenSearch Service, below `aws/$account/$region/opensearch`.

- [Source Code](https://github.com/marcbran/jsonnet-plugin-aws/tree/main/pkg/arcourse-aws-opensearch): Original source code

- [Inlined Code](https://github.com/marcbran/jsonnet/blob/arcourse/aws/arcourse-aws-opensearch/arcourse/aws/arcourse-aws-opensearch/main.libsonnet): Inlined code published for usage in other projects

## Installation

You can install the library into your project using the [jsonnet-bundler](https://github.com/jsonnet-bundler/jsonnet-bundler):

```shell
jb install https://github.com/marcbran/jsonnet/arcourse/aws/arcourse-aws-opensearch@arcourse/aws/arcourse-aws-opensearch
```

Then you can import it into your file in order to use it:

```jsonnet
local arcourse-aws-opensearch = import 'arcourse/aws/arcourse-aws-opensearch/main.libsonnet';
```

## Description

Generated by jsonnet-aws from the plugin's Smithy model, its resource-tree rules and the
overrides, columns and links in services/opensearch/inference. The account and region nodes come from arcourse-aws.
