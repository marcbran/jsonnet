# arcourse/aws/arcourse-aws-rds

- [Source Code](https://github.com/marcbran/jsonnet-plugin-aws/tree/main/services/rds/arcourse): Original source code

- [Inlined Code](https://github.com/marcbran/jsonnet/blob/arcourse/aws/arcourse-aws-rds/arcourse/aws/arcourse-aws-rds/main.libsonnet): Inlined code published for usage in other projects

## Installation

You can install the library into your project using the [jsonnet-bundler](https://github.com/jsonnet-bundler/jsonnet-bundler):

```shell
jb install https://github.com/marcbran/jsonnet/arcourse/aws/arcourse-aws-rds@arcourse/aws/arcourse-aws-rds
```

Then you can import it into your file in order to use it:

```jsonnet
local arcourse-aws-rds = import 'arcourse/aws/arcourse-aws-rds/main.libsonnet';
```

## Description

Generated by jsonnet-aws from the plugin's Smithy model, its resource-tree rules and the
overrides, columns and links in ../inference. The account and region nodes come from arcourse-aws.
