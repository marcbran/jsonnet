# arcourse/aws/arcourse-aws-iam

> Arcourse nodes for AWS Identity and Access Management, below `aws/$account/iam`.

- [Source Code](https://github.com/marcbran/jsonnet-plugin-aws/tree/main/pkg/arcourse-aws-iam): Original source code

- [Inlined Code](https://github.com/marcbran/jsonnet/blob/arcourse/aws/arcourse-aws-iam/arcourse/aws/arcourse-aws-iam/main.libsonnet): Inlined code published for usage in other projects

## Installation

You can install the library into your project using the [jsonnet-bundler](https://github.com/jsonnet-bundler/jsonnet-bundler):

```shell
jb install https://github.com/marcbran/jsonnet/arcourse/aws/arcourse-aws-iam@arcourse/aws/arcourse-aws-iam
```

Then you can import it into your file in order to use it:

```jsonnet
local arcourse-aws-iam = import 'arcourse/aws/arcourse-aws-iam/main.libsonnet';
```

## Description

Generated by jsonnet-aws from the plugin's Smithy model, its resource-tree rules and the
overrides, columns and links in services/iam/inference. The account nodes come from arcourse-aws.
