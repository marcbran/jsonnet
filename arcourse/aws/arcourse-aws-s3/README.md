## Installation

You can install the library into your project using the [jsonnet-bundler](https://github.com/jsonnet-bundler/jsonnet-bundler):

```shell
jb install https://github.com/marcbran/jsonnet/arcourse/aws/arcourse-aws-s3@arcourse/aws/arcourse-aws-s3
```

Then you can import it into your file in order to use it:

```jsonnet
local arcourse-aws-s3 = import 'arcourse/aws/arcourse-aws-s3/main.libsonnet';
```
