# arcourse/aws/arcourse-aws-ec2

> Arcourse nodes for Amazon Elastic Compute Cloud, below `aws/$account/$region/ec2`.

- [Source Code](https://github.com/marcbran/jsonnet-plugin-aws/tree/main/pkg/arcourse-aws-ec2): Original source code

- [Inlined Code](https://github.com/marcbran/jsonnet/blob/arcourse/aws/arcourse-aws-ec2/arcourse/aws/arcourse-aws-ec2/main.libsonnet): Inlined code published for usage in other projects

## Installation

You can install the library into your project using the [jsonnet-bundler](https://github.com/jsonnet-bundler/jsonnet-bundler):

```shell
jb install https://github.com/marcbran/jsonnet/arcourse/aws/arcourse-aws-ec2@arcourse/aws/arcourse-aws-ec2
```

Then you can import it into your file in order to use it:

```jsonnet
local arcourse-aws-ec2 = import 'arcourse/aws/arcourse-aws-ec2/main.libsonnet';
```

## Description

Generated by jsonnet-aws from the plugin's Smithy model, its resource-tree rules and the
overrides, columns and links in services/ec2/inference. The account and region nodes come from arcourse-aws.
